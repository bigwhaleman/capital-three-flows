# 资本三流耦合模型 v2：先读参考站，再重建动力学

研究与实现日期：2026-11-14。性质：**可运行的结构情景模型，附独立的真实交易观测层；不是已校准预测器。**

## 1. 参考站实际做了什么

本轮实际读取了用户给定的 SFO-V5 网站首页、模型工作台、说明、公开脚本和日更数据帧。读取时间为北京时间 2026-11-14 21:50—21:53。公开帧署期 2026-11-14 11:25；不把访问时间当行情时间。URL：
https://wbapp-wmbv2t6xmnfyoinbr26r7j.app.workbuddy.host/?sharecode=HASTKAG67H&shareId=80a6844c7a72455b80a8bc7ac9923217

它不是一个简单行情展示站，而是**把宏观叙事编码为耦合常微分方程，再用市场观测修正部分外生驱动的情景模拟器**。

主链是：紧缩冲击 Π → 流速 V 下降 → 压力 P 累积 → 政策响应 R → 流动性与相对吸引力 A 改变 → 流向 D 调整；流量由 F=M·V 输出。利差、汇率预期和风险补偿另形成 X，推动 A。低流速经 Φ(V) 降低方向调整速度，解释「条件变了、资金未立刻转向」。

### 值得保留的四点

1. **三流互相作用，而不是三个并列数据卡。**有状态、有反馈、有滞后，也能比较干预前后。
2. 把「方向有利」与「资金能够迁移」分开；这与我们的边际开关及执行约束可以结合。
3. 界面直接回答当前状态、驱动变化、未来路径、逆转条件；参数改变会真正重算。
4. 公开方程、数据时间和情景标定性质，并用对照积分说明行情输入的边际贡献。

### 需要改进的不是全部推倒，而是六处连接

| 环节 | 公开实现的情况 | 融合方案 |
|---|---|---|
| 流量量纲 | 用三地股债规模 M 与归一化 V 相乘；没有实际投资者交易闭合 | 先定义可配置投资者池，逐条迁移形成 L；v=L/W。未知池规模用资本指数，不输出虚构美元规模 |
| 方向 | D 为 tanh(A/θ) 的滞后状态，份额再由 D 线性映射 | 用资产间迁移率生成净方向和持仓；不另造一条可以与持仓冲突的 D |
| 可选去向 | 主要是美、中、港三地重分配 | 股债分开，加入美元现金、黄金和第三地；香港同时是经营风险归属问题与交易路由，不当万能第三国 |
| 时点 | t_tp=17、t_ng=17.5 月的预设转折参与产生 2027 年窗口，主窗口长度设为 12 个月 | 只给可改的条件路径和松弛时间，越界、持续及退出由方程计算；允许期限内不逆转 |

| 更新 | 日更帧、浏览器每 60 秒重读、按系统时刻积分是不同动作 | 新观测只更新观测层；没有可识别映射时不自动改成「当前真实三流」 |

技术细节：公开页同时出现「美−中」和负利差的表述，而代码 carry 按美−中为正、确认线为 +200 bp；需统一符号。过去即期升值不等于未来升值预期；单日南向正流不能检验年度阈值；累计结售汇顺差不能证明连续各月均为正。A=0 在固定其他状态时只使稳定点平滑变号，D 方程线性化特征值仍为 −λΦ(V)，不能仅凭变号断言数学分岔。历史最大值锁存可以表达记忆，但不能作为不会失效的现实确认。

这些判断限于公开实现，不评价作者动机，也不声称核实了其本机服务或后台定时任务。学者叙事为机制启发；以下方程与系数均属本项目的形式化选择，不归于学者本人。

## 2. 统一研究对象：七个资产桶、三本账

固定一类投资者的可配置资产：美国股票 Ue、美国债券 Ub、中国经营风险股票 Ce、中国风险债券 Cb、黄金 G、第三地资产 O、美元现金 $。演示不区分不同主体，正式估计须对私人机构、官方储备等分组。

中国风险桶不是内地国际收支口径；港股中的中国经营风险归入 Ce，香港本地资产归 O，香港交易通道另作可达性/成本记录。**居民账、风险账、托管路由账分开**；同一迁移只计一次，不预设港股→债券→A股的固定接力时差。

K_i 为资产持仓，W=ΣK_i，w_i=K_i/W。未取得可配置池的可信美元规模，演示统一令初始 W₀=100 个资本指数点。它不是 100 亿美元，也不是全球市值；给定实际池规模后可以线性换算金额。

## 3. 三流从同一笔迁移生成

f_ij≥0 是每月从 i 移至 j 的配置率，单位资本指数点/月。

L=Σᵢ≠ⱼf_ij；J=Σᵢ∈U,ⱼ∈C(f_ij−f_ji)；v=L/W̄。

- 流量 L：总迁移，资本指数点/月。
- 流向 J：美→中的净迁移，资本指数点/月；正向中国、负向美国，与参考站 D 正向美国的符号相反，页面固定说明。
- 流速 v：月⁻¹，页面用每月占当期资产池的百分比显示。
- 方向指数 D=J/L（L=0 时不定义），无量纲。它度量中美净迁移占全部迁移的份额，不是上涨概率。

同时输出股票 J_e、债券 J_b、跨类迁移及现金净吸收，不用 J 掩盖去往第三地的资金。对每个桶：

**ΔK_i = Δt·(Σ_j f_ji−Σ_j f_ij) + G_i + E_i。**

G 为估值/汇兑，E 为外部注资/提款；纯交易严格守恒。当前演示 E=0，只提供独立的共同估值情景，默认 G=0；不把预期回报直接兑现为已实现收益。全部参数、初始配置均为情景输入，不用市场总市值强行初始化。

## 4. 保留参考站的反馈链，但让记忆可以消退

以月为时间单位，H∈[0,1] 为通道流动性状态，P∈[0,1] 为融资压力，R∈[0,1] 为政策响应。均是模型状态、非官方指数。

H′ = (a+bR)(1−H)−cI(t)H

P′ = [d(1−H)+eZ(t)](1−P)−(f+gR)P

R′ = k{sigmoid[(P−P*)/θ_R]−R}

I(t) 为条件化融资收紧路径，Z(t) 为美元现金需求冲击，二者与 H/P/R 无量纲；a 至 k 中各相应速率单位为月⁻¹。压力累积和政策滞后产生状态记忆，不用永久历史最大值锁存。政策响应只是一个可开关的反应函数假设，不保证现实政策必然救助。

条件路径用 x(t)=x_∞+(x₀−x_∞)exp(−t/τ)，τ 单位月。它描述**假如未来逐渐改变**，不是已估计的预测。没有指定某次会议、9 月 30 日或某个年份必须触发。

## 5. 用我们的边际开关决定迁移目的地

所有收益和风险先统一为未来一个月：

g_i = μ_i^USD − χ_i − γ(Σw)_i；S_ij = g_j−g_i−c_ij。

μ 是同币种、同期限预期回报；χ 是未重复计入协方差的流动性/退出折价；Σ 保留相关性；c 是单次转移成本，允许方向不对称。演示年度预期回报按小回报近似除以 12，年度协方差除以 12；交易成本不除以 12。当前实现中 c 只作执行阻力门槛，尚未从 W 扣除实付佣金或冲击损失，是无费用扣减的研究近似；正式金额核算需把实际费用写入 E，不能同时声称已计入净资产。基点 bp 为 0.01 个百分点。

人民币汇率贡献是**单独输入的预期贡献**，不由最近一天即期变动自动推算。演示给 Ce/Cb 相同的净汇率贡献只是一个公开的简化假设，默认贡献为 0；实际混合币种和香港上市组合须按敞口分别估计，不可机械套用人民币升值。演示不做套保衍生品建模；输入项是套保后或未套保组合的净汇率贡献。未来接入套保时用 μ_USD≈μ_LC−(1−h)EΔlnS+h ln(S/F)−c_FX；须配对期限并避免重复计成本（本轮顺带更正旧报告式(2)漏写的加号）。

协方差用 Σ=BBᵀ+diag(s²) 构造，保证半正定。B 与 s 为公开情景参数，尚未估计。它是均值—方差近似，不声称覆盖尾部风险；美元挤兑另以现金需求约束表示。

### 从局部条件到实际动力学

a_ij = A_ij·max(S_ij,0)/s₀

f_ij^vol = ν₀·H/(H+h₀)·K_i·a_ij/(1+Σ_j a_ij)

A_ij∈[0,1] 为通道可达性；s₀ 为月回报尺度，ν₀ 单位月⁻¹。该式同时满足：无优势不自愿迁移；通道关闭不迁移；从自己的持仓出发；每个出发桶总迁出率有界。它是**有摩擦的边际收益驱动动力学**，不是声称已经求得全球动态最优组合。

在驱动固定、无强制出售、无估值、无外流且微小时间步下，U(w)=μᵀw−χᵀw−γwᵀΣw/2 的方向导数为 Σ f_ij(g_j−g_i)/W≥0；正交易成本形成不交易区。有限时间步另做非负和守恒检查。

### 低流速不意味着所有交易都慢

美元需求提高现金目标 c_min(P,Z)。若现金不足，另有 f_i,$^forced=ν_f·[c_minW−K_$]_+·K_i/(W−K_$)。ν_f 可以高于自愿调整速率，不乘 H 闸门；前提是仍有可执行的资产出售通道，完全封闭资产不参加强售。

因此能同时出现：**自愿跨境配置冻结、被迫卖出加快、美元现金上升**。这比只允许「压力↑→全部流速↓」更完整。现金不足时禁止现金自愿外流；足额后只允许动用高于现金目标的余额。硬流量上限保证每步不会卖出超出持仓的资产。此处只模型化出售换现金，未建模真实基金赎回、融资违约或交易冲击成本。

## 6. 三个阶段和一段可终止窗口

1. **经济边际触发 T_S**：同类资产美→中的股票或债券优势 S 首次由非正转正。只是局部必要信号，现金可能更有利。
2. **模型迁移翻转 T_J**：此前 J<0，随后 J>0；起始即为正应写「起点已偏向中国」，不伪造一次逆转。
3. **持续配置确认 T_C**：截至当月，连续 m 个月 J>0、n_C>0、n_U<0。三者同时成立才标「美出中入」；m 是可改情景参数，默认 3 个月不构成经验规律。

连续成立区间在任一条件失效时结束；到演算终点仍成立记「右删失/观察范围内仍持续」，不硬加 12 个月。回溯起点和当时能够确认的日期分开。

用 27 组确定性扰动检验：远端回报差 ±1 个百分点、执行速度 ×0.7/1/1.3、成本 ×0.7/1/1.3。报告触发组数、未触发组数和触发组的最早/最晚月；**不是 27 个等概率世界，不解释为胜率或置信区间**。当前演示未做结构模型族不确定性、参数后验或样本外概率校准。

## 7. 观测层怎样对模型形成约束

真实观测独立展示：美国财政部国际资本流动统计（Treasury International Capital，TIC）表 1 的外国居民对美长期证券净交易、股债分项、中国内地和香港居民分项；表 5 的美债持仓；欧洲中央银行参考汇率。

净交易 q 使用亿美元/月，净配置强度 q/平均持仓是**净额代理**，不是模型毛流速 v。价格重估与持仓变化另外展示，不通过美元价格自动合成真实 L/J/v。总计明确用 Grand Total，分地区不是最终受益人穿透；中港相加不等于全部中国最终资金。

这些序列可以约束美国吸收端、资产分化和居民来源，但不能单独识别全球美→中迁移。当前不把它们自动塞进未拟合的状态估计器：**真实数据会自动更新，模型只随明确输入重算；二者关系透明而非强行相连。**

下一步实证顺序：固定投资者和分类映射 → 取得双方交易/持仓及现金序列 → 对账与部分识别 → 估计回报/流动性响应 → 与方向不变、自回归基准做滚动样本外比较。未完成这些步骤，不给现实逆转概率。

## 8. 演示应呈现什么

不是科普小游戏，也不是假实时资金雷达。主屏依次为：真实交易观测及分化结论 → 机制情景下的三流与资本去向 → 流动性/压力/政策曲线 → 触发、翻转、持续窗口 → 参数与敏感性。完整推导、参考站评阅和来源放二级页。

四个具名条件情景：缓慢再平衡、回报修复加快、美国优势延续、美元现金挤兑；没有概率权重。初始配置、回报、风险、摩擦及压力均可查，关键参数可改、结果可导出、链接可复现。
