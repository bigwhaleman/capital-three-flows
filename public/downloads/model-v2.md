# 资本三流耦合模型 V2.1：机制诊断、双向闭环与部分识别升级

研究与升级日期：2026-11-15（基于 2026-11-14 V2.0 与 2026-11-13 结构底稿升级）。性质：**可运行的结构情景动力学模型，附独立的真实交易/持仓观测层与精确部分识别区间；不是已校准的经验预测器。**

## 1. 对 V2.0 模型的七项关键诊断与直接改进

在对既有 V2.0 模型代码（`engine.mjs` / `workbench.mjs` / `update_data.py`）与理论底稿进行逐式核对后，识别出七处影响机制闭合与实证解释力的实质问题，并已在 V2.1 直接完成改进：

| 诊断维度 | V2.0 存在的问题 | V2.1 直接改进方案 |
|---|---|---|
| **1. 宏观—资金单向脱钩** | 状态方程 $(H,P,R)$ 完全不依赖资产持仓 $K$ 或迁移流 $f$，美国股债大幅净流出对再融资压力 $P$ 零反馈 | 引入美国证券净流出率 $[-N_U/W]_+$ 对压力 $P$ 的内生反哺系数 $\beta_{\text{flow}}$（可调，设 0 退回单向基准），闭合“资金外流 $\to$ 再融资压力上升 $\to$ 逼迫政策响应或挤兑”回路 |
| **2. 利率与避险定价死锁** | 美元现金预期收益固定为 3%、美债固定 4.5%、黄金固定 4.5%，紧缩 $I$ 不产生高息虹吸，政策响应 $R$ 不降低美元现金套息锚 | 打通 $(I,P,R)\to \mu_i$：紧缩 $I$ 抬升美元现金收益率形成“速冻高息虹吸”，宽松 $R$ 压低美元现金锚并提振久期与黄金，压力 $P$ 触发黄金避险溢价 |
| **3. 借道现金绕费漏洞** | `cost(i,j)` 仅对美股债与中资股债直接互转收 `costUC/costCU`，经美元现金或黄金进出中资桶被硬编码为 3 bp，违反三角不等式 | 按管辖权与结算边界重构分层成本矩阵：任意非中资桶进入中资桶均收 `costUC`、退出均收 `costCU`，美债—美元现金互转 1 bp，同市场股债 2 bp，全局满足 $c_{ik}+c_{kj}\ge c_{ij}$ |
| **4. 单一直连 $J$ 的盲区与文实不符** | ① 文档声称输出 $J_e,J_b,J_{\text{cross}}$ 但代码未实现；② 先卖美股囤美元现金、再用美元现金买中资资产的两步迁移在 $J$ 中记为 0；③ 未区分“离开美股债”与“离开广义美元体系” | 同步输出 $J=J_e+J_b+J_{\text{cross}}$、中国总净流入 $N_C$（含现金池与第三地中转）、美国证券净流 $N_U$ 及**广义美元体系净吸收 $N_{\text{USD}}=N_U+n_{\$}$**，双层检验直连窗口与广义美元出池窗口 |
| **5. 流速混同与强售互挤** | 挤兑期自愿配置冻结但强售飙升，单一总流速 $v$ 掩盖反向运动；持仓超限时自愿调仓按比例挤占强售额度；第 0 月瞬时率受步长 `dt` 污染 | 改为**强售字典序优先**：先在可售头寸内执行现金底线强售，剩余头寸再做自愿配置；拆分自愿流速 $v_{\text{vol}}$ 与强售流速 $v_{\text{forced}}$；消除第 0 月步长依赖 |
| **6. 角点清零、套保同质化与一阶欧拉误差** | 债券低方差使线性均值—方差在 36 个月把美债或第三地推向 0% 角点清零；中资股债共用同一汇率敞口；显式欧拉步长误差约 0.18 点，且跨类边可使 $T_{\text{flip}}<T_S$ | 加入机构基准容量弹性 $\eta(w_i-w_{i,0})$ 保证目标严格凹与内点均衡；增加中债外汇套保比例 $h_b$；累计摩擦损耗并支持实扣模式；升级**二阶保正守恒 Heun (RK2)** 积分（步长折半误差降至 $\sim 0.0012$ 点）；修正全直连边触发时序 $T_S\le T_{\text{flip}}<T_C$ |
| **7. 观测层漏展表 5 分化且缺识别桥接** | 已采集的 TIC 表 5 美债存量与 SAFE 核实档案未在界面展示；未把理论报告 §6.2 的部分识别写成可算工具 | 解析并展示 TIC 表 5 **外国官方储备 vs 私人部门**、**内地 vs 香港**存量分化，接入中美双侧统计档案，并在引擎与界面内置**三区域网络守恒 LP 部分识别求解器** `identifyBounds` |

## 2. 统一研究对象：七个资产桶、三本账

固定一类国际可配置投资者集合的可配置资产：美国股票 $U_e$、美国债券 $U_b$、中国经营风险股票 $C_e$、中国风险债券 $C_b$、黄金 $G$、第三地资产 $O$、美元现金 $\$$。

- **居民账、风险账、托管路由账分开**：港股中的中国经营风险归入 $C_e$，香港本地资产归 $O$，香港结算与通道约束进入可达性 $A_{ij}$ 与交易成本 $c_{ij}$。
- **资本指数标尺**：未取得全球同一可配置池的精确美元本金时，令初始 $W_0=\sum_i K_{i,0}=100$ 个资本指数点，不冒充全球总市值。

## 3. 存量—流量守恒与多维三流分解

设 $f_{ij}\ge 0$ 为每月从桶 $i$ 移至桶 $j$ 的配置率（资本指数点/月），单步内含交易费扣减开关 $\kappa\in[0,1]$（默认 $\kappa=0$ 保持纯配置指数 $W\equiv 100$，同时精确累计摩擦损耗 $C_{\text{cum}}$）：

$$\Delta K_i = \Delta t\left[\sum_{j\ne i} f_{ji}(1-\kappa c_{ji}) - \sum_{j\ne i} f_{ij}\right] + G_i$$

从同一迁移矩阵 $f_{ij}$ 同源导出：
- **流量分解**：总流量 $L=\sum_{i\ne j} f_{ij} = L_{\text{vol}} + L_{\text{forced}}$；
- **直接双边流向分解**：
  $$J = J_e + J_b + J_{\text{cross}}, \quad J_e = f_{U_e,C_e}-f_{C_e,U_e},\quad J_b = f_{U_b,C_b}-f_{C_b,U_b},\quad J_{\text{cross}} = (f_{U_e,C_b}-f_{C_b,U_e})+(f_{U_b,C_e}-f_{C_e,U_b})$$
- **目的地与广义美元体系净流**：
  $$N_C = n_{C_e}+n_{C_b},\qquad N_U = n_{U_e}+n_{U_b},\qquad N_{\text{USD}} = N_U + n_{\$},\qquad N_{\text{alt}} = n_G + n_O$$
  满足全局守恒恒等式 $N_{\text{USD}} + N_C + N_{\text{alt}} \equiv 0$。当 $N_U<0$ 但 $N_{\text{USD}}\ge 0$ 时，资金只是从美股美债退入美元现金池（**美元体系内避险虹吸**），并非资本离开广义美元体系；仅当 $N_{\text{USD}}<0$ 且 $N_C>0$ 时，才构成实质性的广义美元净出池向中配置（差额 $N_C - J$ 即经由美元现金或第三地中转的间接净配置）。
- **双轨流速与净位移效率**：
  $$v = \frac{L}{\overline{W}} = v_{\text{vol}} + v_{\text{forced}},\qquad \text{Eff} = \frac{\sum_i |n_i|}{2L}\in[0,1].$$

## 4. 双向耦合宏观状态方程与定价传导

以月为时间单位，$H\in[0,1]$ 为通道流动性，$P\in[0,1]$ 为再融资压力，$R\in[0,1]$ 为政策响应：

$$H' = (a+bR)(1-H) - cI(t)H$$
$$P' = \left[d(1-H) + eZ(t) + \beta_{\text{flow}}\max\!\left(0,\;-\frac{N_U}{W}\right)\right](1-P) - (f+gR)P$$
$$R' = k\left\{\operatorname{sigmoid}\!\left(\frac{P-P^*}{\theta_R}\right) - R\right\}$$

其中 $\beta_{\text{flow}}[-N_U/W]_+$ 刻画美国股债遭遇外部净抛售时对融资压力的内生放大效应。

### 利率、外汇套保与容量弹性边际开关

各桶年化预期美元回报纳入紧缩、压力与政策传导（$\rho$ 为传导强度 `ratePass`，$h_b$ 为中债外汇套保比例 `bondHedge`）：
- 美元现金：$\mu_{\$} = 3 + 1.4\rho I(t) - 1.8\rho R$（紧缩期高息虹吸，宽松期套息消退）；
- 美国股票 / 债券：$\mu_{U_e} = 8 - 1.2P + 0.8\rho R$，$\mu_{U_b} = 4.5 + 0.35\rho I(t) + 0.9\rho R - 0.6P$；
- 中国风险股票 / 债券：$\mu_{C_e} = \mu_{U_e} + \text{gap}_e(t) + \text{fx}$，$\mu_{C_b} = \mu_{U_b} + \text{gap}_b(t) + (1-h_b)\text{fx}$；
- 黄金 / 第三地：$\mu_G = 3.2 + 2.6[P-0.25]_+ + 1.1\rho R - 0.4\rho[I(t)-0.5]_+$，$\mu_O = 6.5 - 0.8P + 0.5\rho R$。

转换为月度口径后，扣除退出折价 $\chi_i(P)$、因子协方差边际风险 $\gamma(\Sigma w)_i$ 及机构基准容量弹性项 $\eta(w_i - w_{i,0})$，得到边际净收益 $g_i$ 与扣费迁移优势 $S_{ij}=g_j-g_i-c_{ij}$。因 $\gamma\Sigma + \eta I \succ 0$，配置目标严格凹，消除角点清零失真。

### 字典序优先强售与二阶保正守恒积分

1. **优先强售补足现金底线**：当 $K_{\$} < c_{\min}(P,Z)W$ 时，先在可售非现金资产内按比例执行 $f_{i,\$}^{\text{forced}} = \min(K_i^{\text{elig}}/\Delta t,\; \nu_f[c_{\min}W-K_{\$}]_+\cdot K_i^{\text{elig}}/E)$；
2. **剩余可用头寸自愿迁移**：以未质押/未强售余额 $K_i^{\text{rem}} = K_i - \Delta t f_{i,\$}^{\text{forced}}$（现金桶取 $[K_{\$}-c_{\min}W]_+$）经过流动性闸门 $\nu_0 H/(H+h_0)$ 执行边际迁移；
3. **二阶保正守恒 Heun (RK2)**：由阶段通量满足 $\Delta t\,\text{out}_1\le K_i$ 与 $\Delta t\,\text{out}_2\le K_i^{\text{pred}}$，可严格证明梯形平均通量满足 $K_i^{\text{new}}\ge \frac{1}{2}K_i + \frac{\Delta t}{2}\text{in}_2 \ge 0$，无需事后截断即精确保持非负与总和守恒。

## 5. 聚合净额下的双边流向部分识别（Partial Identification）

现实公开数据（如美国 TIC 表 1、中国国际收支证券项）通常仅披露各地区或资产桶的净流量而缺乏穿透对手方。在三区域守恒网络 $(U, C, R)$ 中，给定观测区间 $n_U\in[\underline{n}_U,\overline{n}_U]$、$n_C\in[\underline{n}_C,\overline{n}_C]$、直连通道上限 $(\bar{f}_{UC},\bar{f}_{CU})$、第三地/现金中转上限 $\bar{f}_R$ 及可选总毛流量上限 $\bar{L}$，中美直接净迁移 $J_{UC}=f_{UC}-f_{CU}$ 的精确可行闭区间由解析线性规划给出：

$$J_{UC} \in \big[\max(-\bar{f}_{CU},\; -\overline{n}_U-\bar{f}_R,\; \underline{n}_C-\bar{f}_R),\; \min(\bar{f}_{UC},\; -\underline{n}_U+\bar{f}_R,\; \overline{n}_C+\bar{f}_R)\big] \cap \{J : L_{\min}(J)\le \bar{L}\}$$

- 仅当 $\underline{J}_{UC}>0$（即美国净流出或中国净流入超出第三地最大中转吞吐，或总换手上限排除绕道循环）时，才能从聚合净额稳健识别“美→中直接净迁移为正”；
- 若区间跨零，引擎同时输出上界与下界对应的构造性六边见证网络，直观展示零空间循环如何使相同净额对应相反的双边方向。
