# 资本三流动态研究台 V2.1

2026-11-15 升级版（在 V2.0 融合模型基础上完成七项结构机制、数值求解与部分识别改进）。旧版归档保留。

## V2.1 核心改进
- **双向宏观反馈闭环**：美国股债净流出率 $[-N_U/W]_+$ 内生反哺再融资压力 $P$，闭合资金流动与宏观压力双向耦合。
- **利率套息锚与避险传导**：融资紧缩 $I(t)$ 抬升美元现金收益率（速冻期高息虹吸），政策响应 $R$ 压低现金锚并联动美债与黄金，中债支持独立外汇套保比例。
- **防套利跨境成本矩阵**：对全部非中资桶进出中资桶统一适用跨境准入/退出摩擦，严格满足三角不等式 $c_{ik}+c_{kj}\ge c_{ij}$，堵死借道美元现金绕费漏洞。
- **直连迁移与广义美元池分离**：同源输出 $J=J_e+J_b+J_{\text{cross}}$、中国总净流入 $N_C$ 与广义美元体系净吸收 $N_{\text{USD}}=N_U+n_{\$}$，区分“退入美元现金”与“实质离开美元体系”。
- **强售字典序优先与双轨流速**：现金短缺时优先执行强制变现，拆分受流动性 $H$ 约束的自愿流速 $v_{\text{vol}}$ 与强售流速 $v_{\text{forced}}$。
- **容量弹性与二阶保正守恒积分**：引入机构基准容量弹性消除单一资产 0% 角点清零失真；升级二阶保正守恒 Heun (RK2) 积分，步长折半误差降至 $\sim 0.0012$ 指数点。
- **观测层补齐表 5 官方/私人持仓分化与 LP 部分识别计算器**：完整展示 TIC 表 5 外国官方储备 vs 私人部门、内地 vs 香港存量曲线、中美双侧核实统计档案，并内置双边净流精确上下界求解器。

## 重要口径
模型初始资本池为 100 **资本指数点**，不是全球美元市值。回报、协方差、反馈强度与容量弹性均为公开情景参数，尚未经历史样本回归拟合。真实数据按官方发布滞后更新，未拟合状态映射前不伪造“当期真实三流”。完整说明见 `public/downloads/model-v2.md`。
