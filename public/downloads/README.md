# 资本三流动态看板 V2.3（高频桥接即时估算版）

2026-11-15 升级版：在 V2.2 直观看板与七资产二阶守恒耦合模型基础上，新增**美联储 H.4.1 周度官方托管 + 美国财政部附息国债拍卖高频桥接估算（Bridge Nowcast）**，将自动采集源由 7 路扩展至 **9 路零密钥官方源**，并在同一张图表中清晰展示**「实线官方实测 + 虚线高频估算与 80% 留一法预测区间」**。

## V2.3 高频桥接版核心升级
- **填补 TIC 月报 ~2.5 个月滞后盲区**：针对美国财政部 TIC 月报约 65–75 天发布滞后，接入滞后仅 3 天的美联储 H.4.1 官方托管周报与实时截标的财政部附息国债（Note/Bond）拍卖结果，自动对尚未公布 TIC 的近月（如 `2026-09`、`2026-10`、`2026-11` 月初至今）给出点估计与 80% 置信区间；新一期 TIC 发布后自动向后顺延。
- **同图「实线实测 + 虚线区间」分层可视化**：SVG 图表引擎原生支持 `80% 置信扇形带`、`实测 | 估算分界线` 与 `实线圆点 → 虚线空心圆环` 无缝衔接，一眼区分已交割实测与高频桥接估算。
- **9 路官方与主市场零密钥直连数据源**（全部无需 API Key，单源故障保留旧快照）：
  1. 欧洲央行 ECB 参考汇率与 90 日历史（`USD/CNY`、`USD/HKD`、六币权重美元指数）
  2. 美国财政部每日国债收益率曲线（`10Y / 2Y / 3M` 及 60 日曲线）
  3. 中国外汇交易中心 CFETS 国债收益率（`10Y / 1Y` 及 60 日中美 10Y 利差序列）
  4. 纽约联储 NY Fed 隔夜有担保融资利率 `SOFR`（利率 + 回购成交量）
  5. 芝加哥期权交易所 Cboe `VIX` 恐慌指数日收盘序列
  6. 美国财政部 TIC 表 5（内地、香港、全球及**外国官方储备 vs 私人部门**美债存量）
  7. 美国财政部 TIC 表 1（全球、内地、香港对美长期证券月度净买卖、股债分项与估值核对）
  8. **美联储 H.4.1 周报外国官方托管证券**（`RESH4F_N.WW` / `RESH4FG_N.WW` 可流通美债周三存量与月度差值）
  9. **美国财政部中长期附息国债拍卖**（合并 `FiscalData` 历史交割与 `TreasuryDirect` 最新截标，核算 `Indirect Bidders` 海外间接获配占比与 `Primary Dealers` 被动兜底占比）
- **经济符号单调约束与诚实国别边界**：债券桥接采用非负单调岭回归（确保海外拍卖占比回落与联储托管减持单调压低估算净买），并由历史留一法交叉验证（LOOCV）量化均方根误差；由于周度托管与美债拍卖不披露分国别明细，系统绝不伪造中国内地或香港近月单月净买卖点估计。
