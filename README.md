# 资本三流动态看板 V2.2（直观看板版）

2026-11-15 升级版：在 V2.1 七资产二阶守恒耦合模型与精确部分识别引擎基础上，升级为**浅色智库级直观看板 + 7 路官方日频/月频零密钥信号 + 一屏精简汇报版**。

## V2.2 直观看板版核心升级
- **五页渐进披露架构**：默认落地 `01 今日看板`（`#overview`，30 秒读懂今日定论、四张大白话核心卡片、五项逆转条件核对表、日频市场温度计与四种未来推演卡），新增 `02 精简汇报版`（`#brief`，PPT 式一屏可打印/分享的四宫格执行摘要），完整保留 `03 模型工作台`（`#model`）、`04 真实资金账`（`#observed`）与 `05 原理与说明`（`#method`）。
- **浅色智库排版 + 深浅双主题切换**：默认采用高可读浅色编辑部/宏观研报风格，支持右上角 `☀ 浅色 / ☾ 深色` 一键切换与打印排版优化。
- **7 路官方与主市场零密钥直连数据源**：由原有的 3 路扩展为 **7 路**（全部无需 API Key，单源故障保留旧快照）：
  1. 欧洲央行 ECB 参考汇率与 90 日历史（`USD/CNY`、`USD/HKD`、六币权重美元指数）
  2. 美国财政部每日国债收益率曲线（`10Y / 2Y / 3M` 及 60 日曲线）
  3. 中国外汇交易中心 CFETS 国债收益率（`10Y / 1Y` 及 60 日中美 10Y 利差序列）
  4. 纽约联储 NY Fed 隔夜有担保融资利率 `SOFR`（利率 + 回购成交量）
  5. 芝加哥期权交易所 Cboe `VIX` 恐慌指数日收盘序列
  6. 美国财政部 TIC 表 5（内地、香港、全球及**外国官方储备 vs 私人部门**美债存量）
  7. 美国财政部 TIC 表 1（全球、内地、香港对美长期证券月度净买卖、股债分项与估值核对）
- **五项逆转条件核对表**：用实测数据实时核对人民币汇率定力、中美 10Y 利差、美元隔夜现金套息锚 SOFR、官方储备降久期与外资月度净买降温五项条件，直接点明当前已完成项与核心卡点。
- **底层模型严谨度零妥协**：完整保留 V2.1 双向宏观反馈、分层防套利成本矩阵、直连 $J$ vs 广义美元池 $N_{\text{USD}}$ 分离、强售字典序优先、容量弹性、二阶保正守恒 RK2 积分与三区域 LP 部分识别计算器。

## 重要口径边界
- **不伪造盘中实时跨境成交额，不硬编码“某年某月必然逆转”倒计时**：日频利率/汇率/VIX 与月频官方 TIC 交割数据严格分标日期与统计滞后。
- 模型初始资本池为 100 **资本指数点**，属于公开参数条件推演，不等同于投资建议或样本外预测胜率。完整技术说明见 `public/downloads/model-v2.md`。
